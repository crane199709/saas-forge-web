## 创建校验反馈修复（2026-09-27）

用户在正式页面填写编码 `1001`、名称“测试套餐”、人数 10 后被拦截。核对 Client 0.4.0 发布来源 `ebff4b338d0c4b39e51488ac1e9b98885318d438` 中的正式 CreatePlanRequest，编码要求 `^[a-z][a-z0-9-]{1,62}$`；纯数字编码不满足契约，不放宽该规则。

Chrome 模拟 HTTP 复现确认该输入没有发送创建 POST，但原页面错误地把名称、人数也标为无效，并只显示合并提示。改为字段独立提示，增加编码规则与 `plan-1001` 示例，提交时聚焦首个错误字段。修复后同一输入仅编码无效，改成 `plan-1001` 后正式 Client 发出一次创建请求。该请求响应仍为测试模拟，不代表真实创建成功。

同时修复 BaseLayout 多根节点导致父级 class 无法自动继承的 Vue 警告：关闭自动继承，并显式将属性传给实际 AdminLayout，保留原有会话核查模态层。相同 Chrome 复现中该警告从 1 次降为 0 次。

权益 37 项、全量 93 项测试、类型检查通过；已有模拟 Chrome 页面回归继续覆盖原操作恢复、整数边界、历史只读、键盘焦点和主题。当时真实后端验收仍未执行；随后补齐结果如下。
