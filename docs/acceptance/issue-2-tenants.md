## 交付内容

- 平台菜单 `/tenants`：正式 Client 查询、名称/状态筛选、游标分页和重置。`/tenants/:id` 为独立详情，刷新深链接保持当前详情，不被会话例行检查跳回首页。
- Element Plus 创建抽屉、脏表单离开确认、浏览器关闭提示、右对齐动作和明确的关闭/返回名称。详情仅展示权威 Tenant 字段，后续订阅、初始化和生命周期功能按各自票接入。
- 每 Realm 的 Tenant Workspace 沿用统一会话凭据；页面不接触 Token、浏览器安全头或幂等键。创建前核查当前操作者完整创建记录，分页不完整、游标循环、重复记录、字段不完整和网络失败均关闭写入口。
- 创建未知结果保留原幂等身份且禁止再次提交。恢复动作重新读取权威记录，只用其原句柄及原幂等键调用正式 recovery operation。未找到记录不解除已知未知提交锁；暂时会话失败也不能解除。换账号或退出清除私有材料，旧在途响应失效。
- 恢复材料只在内存中存在；页面真正重载后通过服务端当前操作者记录发现原操作，不能声称本地持久化了句柄。超过保留期、服务端记录缺失或无法确认的结果仍需人工核查。
- 中英文和带时区的时间点展示；Tenant ID 不转为 Number。

迁入的提交补丁、源文件和适配边界见 [业务来源](../migrations/issue-2-tenant-source.md)。历史内容不作为本轮验收依据。
